# MelodyNode
Lightweight playlist desktop application for creating, organizing and storing music and songs in Mp3 or Mp4 format.

It's already launched on Microsoft Store following their packaging configurations.

👉 **[Download MelodyNode v1.0.0 (Latest Release)](../../releases/latest)**

* **Recommended:** Download the **`.exe`** installer for quick setup.
* **Alternative:** Download the **`.msix`** package from the **Assets** section at the bottom of the release page.
